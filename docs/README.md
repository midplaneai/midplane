# Midplane documentation

The source of <https://midplane.ai/docs>, built with
[Mintlify](https://mintlify.com): pages are `.mdx`, navigation and redirects
are in `docs.json`. Read the docs there; [AGENTS.md](AGENTS.md) has the terms,
style and checks for changing them.

```sh
npx --yes mint@4.2.970 dev   # preview at http://localhost:3000
```
